# プライバシーポリシー

**アプリ名**: カクテル手帖
**最終更新日**: 2026年5月10日

studio-rk（以下「当方」）は、Android アプリ「カクテル手帖」（以下「本アプリ」）のプライバシーポリシーを以下のとおり定めます。

## 1. 収集する情報

本アプリは、ユーザーの個人情報を一切収集しません。

ユーザーが本アプリで作成・編集したカクテルレシピ等のデータは、ユーザーの端末内にのみ保存され、当方のサーバーや第三者に送信されることはありません。

## 2. 第三者サービス

本アプリは、現時点で広告 SDK・解析 SDK・クラッシュレポート SDK を組み込んでいません。

将来的にこれらを導入する場合は、本ポリシーを更新したうえで該当 SDK の取り扱う情報・利用目的を明記します。

## 3. 権限

本アプリが要求する Android パーミッションは、機能提供に必要な最小限のものに限定します。各権限の目的は以下のとおりです。

- 現時点で特別な権限は要求していません。

## 4. 子どもの利用について

本アプリはアルコール飲料に関する情報を扱うため、20 歳未満の方の利用は推奨しません。

## 5. データの削除

本アプリ内のデータはすべてユーザーの端末に保存されているため、アプリをアンインストールすることで完全に削除されます。

## 6. ポリシーの変更

本ポリシーは予告なく改定されることがあります。重要な変更がある場合はアプリ内またはストアの更新説明にて告知します。
